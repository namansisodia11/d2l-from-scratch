# d2l-from-scratch

Code from the book [Dive into Deep Learning](https://d2l.ai), written **without depending on the `d2l` package**.

Helper functions (plotting, etc.) are copied from the d2l library into each notebook, so every notebook is self-contained.

## Contents

| Notebook | Topic |
|---|---|
| [`03_normal_distribution.ipynb`](03_normal_distribution.ipynb) | Plotting normal distributions (d2l 3.1, linear regression chapter) |
| [`03_object_oriented_design.ipynb`](03_object_oriented_design.ipynb) | Object-oriented design for implementation (d2l 3.2) |

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```
