# d2l-from-scratch

Code from the book [Dive into Deep Learning](https://d2l.ai), written **without depending on the `d2l` package**.

Helper functions (plotting, etc.) are copied from the d2l library into each notebook, so every notebook is self-contained.

## Contents

| Notebook | Topic | Added |
|---|---|---|
| [`03_normal_distribution.ipynb`](03_normal_distribution.ipynb) | Plotting normal distributions (d2l 3.1, linear regression chapter) | 2026-11-09 |
| [`03_object_oriented_design.ipynb`](03_object_oriented_design.ipynb) | Object-oriented design for implementation (d2l 3.2) | 2026-11-10 |
| [`03_synthetic_regression_data.ipynb`](03_synthetic_regression_data.ipynb) | Synthetic regression data (d2l 3.3) | 2026-11-13 |
| [`03_linear_regression.ipynb`](03_linear_regression.ipynb) | Linear regression implementation from scratch (d2l 3.4) | 2026-11-14 |

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```
